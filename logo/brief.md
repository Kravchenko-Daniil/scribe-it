# Бриф: scribe-it

## Что делает проект
Telegram-бот, который за минуту превращает видео/аудио/ссылку в аккуратный текст
с разбивкой по спикерам и таймкодами — без регистраций и веб-интерфейсов.

## Аудитория
- Кто: журналисты, контентмейкеры, подкастеры, исследователи, продакты, студенты —
  всем, кому нужен текст интервью / подкаста / лекции / созвона.
- Уровень: уверенные пользователи Telegram, ценят скорость и отсутствие лишних шагов.
- Где находят: Telegram (по ссылке/рекомендации), сарафан, возможно каталоги ботов.

## 3 эмоции, которые должен вызывать логотип
1. Скорость / мгновенность (за минуту, без шагов)
2. Точность / аккуратность (чистый структурированный текст)
3. Надёжность / простота (просто работает)

## 3 эмоции, которые НЕ должен вызывать
1. Дешевизна / generic AI-mush
2. Корпоративность / бюрократия
3. Детская мультяшность

## 7 существительных вокруг проекта
буквальные: звуковая волна (waveform), микрофон, текстовые строки, субтитры, перо (scribe/писец)
метафорические: поток (звук → текст), превращение/морфинг, искра

## Концепты-кандидаты (метафора для значка)
1. Waveform → text lines — звуковая волна, переходящая в строки текста (точнее всего: audio→text)
2. Перо (quill) — классический символ писца (scribe), можно собрать из waveform
3. Speech bubble — речевой пузырь со строками/волной внутри (нативно для мессенджера)
4. Монограмма «S» — буква S, собранная из звуковой волны

## Конкуренты / референсы (вайб)
Linear, Vercel, Stripe (tech-минимализм) — за чистоту формы и работу с негативным пространством.
Отстроиться от generic «микрофон + ноты» из стоков.

## Палитра — монохромный премиум + 1 акцент
- near-black   #0E0E10  (фон/основной)
- cream         #F2EDE4  (основная фигура на тёмном)
- white         #FFFFFF  (альтернатива кремовому)
- accent Tiffany #0ABAB5 (акцент — голубой тиффани)
Референс-вайб: Linear / Vercel / Stripe, тёмный премиум (ref-4, ref-5).

## Шрифт — кандидаты (Google Fonts)
Space Grotesk / Geist (tech-премиум). Финал выберем на сборке в Figma.

## Тип логотипа
Combination (значок + wordmark). Приоритет — СИЛЬНЫЙ значок в круге:
основное применение = аватарка Telegram + favicon 16×16.

## Технические требования
- Работает в круге аватарки Telegram и на 16×16 favicon
- Версии: color/white/black, на светлом и тёмном фоне
- Основной формат: SVG
